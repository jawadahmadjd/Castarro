# Castarro Codebase Cleanup Audit

Date: 2026-06-25

This note captures the cleanup analysis for the Castarro workspace. It is intentionally conservative: items are marked safe only when they are generated, cached, reinstallable, or not used by the running app. Risky items may be removable, but only after deciding that their history, tests, docs, or tooling are no longer needed. Dangerous items may contain user data, media, app state, secrets, or active product code.

## Project Shape

- `desktop/` is the Electron wrapper. It starts the Python backend, manages tray behavior, native dialogs, auto updates, and packaged runtime paths.
- `scripts/web_ui.py` is the main local HTTP backend. It serves the UI, exposes `/api/*`, controls streams, preview, YouTube, storage, sync, import/export, transfer, and app shutdown.
- `web/` is the desktop web dashboard. `index.html`, `app.js`, and `ui-master.css` are tightly connected.
- `scripts/` contains the backend modules and release/smoke helper scripts.
- `mobile/android/CastarroMobile/` is a separate Android app that is included in release workflows.
- `shared/castarro-core/` is a shared contract package for schemas, fixtures, feature flags, and cross-platform tests.

## Suggested Cleanup Order

1. Backup or move `Raw Videos/`, `Go Live/`, `config.json`, `config.ready.json`, and `stream_control.db` before any cleanup.
2. Remove safe generated folders and files.
3. Run `npm install` or `npm ci`.
4. Run the key desktop tests/scripts that do not require external credentials.
5. Decide whether to keep or archive yellow docs, demos, design mocks, old screenshots, and IDE metadata.
6. Only then consider code-level cleanup such as dropping legacy UI or unused dependencies.

## Verification To Run After Cleanup

- `npm install` or `npm ci`
- `npm run test:ui-master`
- `npm run test:workspace-contract`
- `npm run test:mobile-contracts`
- `npm run test:backend-shutdown`
- `npm run verify:mobile` if Android code or shared contracts were touched
- `npm run bundle:runtime` before packaging if bundled Python/FFmpeg was removed
- `npm run dist` or `npm run release:check` before shipping
